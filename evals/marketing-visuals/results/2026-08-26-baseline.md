# Tiro Marketing Visuals baseline — 2026-08-26

Method: direct observation of the working session that began with the first marketing-visual request and continued through the user's eight-image taste selection. No dedicated marketing-visuals skill existed. This is the RED control for the first three cases.

## Useful baseline behavior

- Established a warm stone and Tironian-brown material world using paper, wood, linen, thread, seams, and layers.
- Avoided literal quills, Roman busts, and direct imitation of the supplied Cursor reference.
- Generated visually distinct space, time, and notation vocabularies.
- Corrected the Korean font subset problem by switching to the full Hahmlet W510 file.
- Built real HTML compositions after the user clarified that text placement mattered.
- Marked investment copy as hypothetical and withheld unsupported voice metrics.

## Failures the skill must correct

### Case 1 — partial fail

The first deliverables over-weighted standalone images. The user had to say:

> 저렇게 단일이미지보다는 저기 위에 글자가 실제로 어떻게올라가는지가 중요한듯

Only then did the workflow formalize `content category × background world × typography template`. The future skill must make this composition model the default from the start.

### Case 2 — fail before the user's taxonomy prompt

Security, compatibility, voice, investment, and other external news did not receive distinct evidence patterns until the user explicitly enumerated them. The skill must classify announcement type before visual generation and keep claims verifiable.

### Case 3 — partial fail

The session successfully explored and synthesized preferences, but the authority hierarchy among references appeared only after the user said:

> 3 5는 이대로 써도 되는정도. 스킬 만들때 나의 현재 기호와 선정된 8개 이미지 기반 무드보드를 참고해줘

The future skill must load 03 and 05 as near-production fidelity references, then use the other six for material and metaphor range. Newly confirmed preferences must be persisted.
