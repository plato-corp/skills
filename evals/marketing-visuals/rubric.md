# Tiro Marketing Visuals behavioral rubric

Score observable decisions and artifacts, not exact wording. A case fails when any applicable mandatory item fails.

## Global mandatory items

- [ ] Distinguishes marketing visuals from product GUI and landing-page design.
- [ ] Records the one sentence a viewer must understand within one second before drawing.
- [ ] Resolves the current Tiro design source and lists only the governing files actually used.
- [ ] Asks once for desired and disliked references when neither was supplied; does not ask again when the request already answers this.
- [ ] Uses the eight-image moodboard as a weighted reference: compositions 03 and 05 are the fidelity bar, while the other six define the wider visual vocabulary.
- [ ] Separates generated imagery from typography; generated backgrounds contain no text, and final Korean copy is composed in HTML or another editable layer.
- [ ] Routes the content to an evidence pattern before choosing a decorative motif.
- [ ] Defines the image purpose as one intended viewer change in the named audience, channel, and time window; does not substitute a visual style or deliverable type for the purpose.
- [ ] Defines “AI-like” as an observable disconnect among purpose, evidence, and visual decisions—not as the use of an AI tool or a fixed aesthetic blacklist.
- [ ] Requires every dominant element to have a message, evidence, structural, or brand role and rejects a candidate that remains interchangeable after swapping the logo and headline.
- [ ] Creates 2–3 variants only when the decision axes are materially different; never pads the report with cosmetic alternatives.
- [ ] Defines 4–6 artifact-specific 10/10 targets and withholds candidates until every critical score is at least 9.0.
- [ ] Records optical type changes as previous value, new value, and reason.
- [ ] Avoids gradients, cool blue/gray tech styling, generic SaaS blobs, generic quills/Roman motifs, fake metrics, and unsupported company claims without misclassifying Tiro's official nib mark as a forbidden origin prop.
- [ ] Does not modify production or publish externally unless the user explicitly requests it.

## Case 1 mandatory items

- [ ] Recognizes the supplied Cursor reference and does not repeat the reference question.
- [ ] Converts the reference into transferable principles rather than visual imitation.
- [ ] Routes the story as a feature release led by product change and a workspace cue.
- [ ] Uses the Tiro origin through capture, compression, notation, or context—not literal historical decoration.
- [ ] Makes the full image-plus-type composition the candidate, not a raw background board.
- [ ] Uses one polished direction when the decision is already clear, or at most 2–3 named alternatives when a material decision remains.

## Case 2 mandatory items

- [ ] Treats “no reference” as answered and proceeds without asking the same question again.
- [ ] Uses the moodboard before broader research; performs external category research only if it can change a material choice.
- [ ] Leads with `SOC 2 Type 2` and verifiable proof, not a generic promise of safety.
- [ ] Rejects padlock/shield/neon cybersecurity clichés and cold blue styling.
- [ ] Keeps channel exports traceable to one canonical composition and verifies current channel dimensions before export when they differ.
- [ ] Does not invent an audit date, certification scope, metric, or seal content.

## Case 3 mandatory items

- [ ] Diagnoses the dissatisfaction across message clarity, hierarchy, type placement, image-to-copy relationship, category evidence, and generic-AI patterns before redrawing.
- [ ] Uses 03 and 05 as the craft/fidelity bar without copying their composition mechanically.
- [ ] Names the report mode switch if the current report shape is part of the problem.
- [ ] Produces 2–3 materially different corrected directions, not a large unfiltered moodboard.
- [ ] States the synthesis rule when combining preferred parts.
- [ ] Persists newly confirmed preference signals into the selection manifest rather than relying only on conversation memory.

## Case 4 mandatory items

- [ ] Distinguishes the official Tiro nib from generic quills, fountain-pen nostalgia, Roman props, and ancient-manuscript cosplay.
- [ ] Allows the official nib to act as a standalone hero object when it serves the one-second message.
- [ ] When a trace begins at the nib, maps it to an actual transition among speech, capture, record, structure, and sharing rather than using it as a decorative squiggle.
- [ ] Rejects a warm pastoral interior as sufficient Tiro specificity; a photo-led candidate must show an observable Tiro role through the official nib, a semantic trace, record evidence, or a verified product cue.
- [ ] Keeps the official brand signature geometrically intact even when a separate nib-derived graphic is rendered materially or dimensionally.

## Case 5 mandatory items

- [ ] Assigns each frame a communication role before applying a visual medium: hero/promise, relationship, transition, boundary/visibility, or verified product proof.
- [ ] Uses a diagram when the viewer must understand hierarchy, containment, transition, sequence, permissions, or visibility; does not substitute atmospheric photography for those relationships.
- [ ] Keeps the hero image-led when appropriate without propagating its medium into every explainer frame.
- [ ] Chooses a diagram grammar that matches the claim: result tree, branching map, nested boundary, state transition, process rail, comparison, or verified annotated product fragment.
- [ ] Uses labels, connectors, grouping, and boundaries semantically; equal cards or repeated nodes appear only when the entities are actually equal.
- [ ] Unifies a mixed-media series through typography, spacing, palette, trace logic, and brand signature rather than forcing every frame into the same composition.
- [ ] Does not invent product structure, permission behavior, or UI; unresolved facts remain conceptual or explicitly labeled for verification.
- [ ] Checks the rendered frame at thumbnail and actual export size for text overlap, clipping, overflow, and unintended line protrusion.
- [ ] Keeps type size, type weight, stroke weight, and spacing within one visual hierarchy; no attempt at editorial personality may compete with comprehension.

## Case 6 mandatory items

- [ ] Writes a purpose statement before proposing a style: `When <audience> sees this on <channel>, they should <recognize / understand / believe / do> <one thing> within <time>.`
- [ ] Names the real evidence that makes the purpose credible and what the image is not trying to communicate.
- [ ] Diagnoses AI-smell with observable tests: purpose causality, element role, evidence traceability, interchangeability, and rendered hierarchy.
- [ ] Does not treat asymmetry, texture, imperfection, or handcrafted styling as automatic proof that the result is less AI-like.
- [ ] Removes or revises any dominant element whose existence cannot be explained from the purpose or verified evidence.
- [ ] Withholds the candidate when replacing the Tiro mark and headline would leave a plausible generic SaaS or lifestyle asset.
- [ ] Renders the complete image-plus-type composition and verifies that the intended viewer change is still legible at one second and thumbnail size.

## Failure patterns to record

- Raw-background substitution: presenting a generated image as if the typography problem were solved.
- Reference repetition: asking for a reference after the requester already supplied one or said none exists.
- Category flattening: using the same headline/evidence anatomy for feature, security, compatibility, voice, and company news.
- Moodboard flattening: treating all eight references as equally authoritative.
- Cliché regression: quill/Roman cosplay, blue lock/shield security, neon waveform, rocket/confetti investment news.
- Nib over-ban: treating Tiro's official nib mark as equivalent to a generic quill or nostalgic writing prop.
- Kinfolk drift: relying on warm interiors, linen, paper, plants, and quiet daylight without an observable record or connection role for Tiro.
- Series flattening: copying the hero's photo or visual treatment into explanatory frames whose job is to show relationships, transitions, or boundaries.
- Diagram theater: adding equal cards, nodes, or connectors that do not encode an actual product relationship.
- Diagram styling overshoot: forcing asymmetry, large type contrast, expressive rules, or branded objects into a diagram until labels collide, lines protrude, or the reading order becomes less stable.
- Numeric-gate false positive: treating node counts, connector counts, grid alignment, or zero-shadow checks as proof that the rendered diagram is visually ready.
- Cliche-only diagnosis: declaring AI-smell solved because known motifs were removed while purpose, evidence, and visual causality remain undefined.
- Brand-swap genericity: a composition still works unchanged for another SaaS after replacing only the logo and headline.
- Unsupported proof: invented certification wording, voice metrics, device support, funding facts, dates, or partners.
- Variant theater: options differ mainly by crop, color, or decoration.
- Average-score laundering: sharing while one critical axis is below 9.0.
