# Announcement patterns

Read the section matching the primary announcement category. Hybrid stories still choose one primary one-second message; secondary facts move into support copy.

## Shared composition anatomy

Every candidate is a complete editable frame:

```text
Category label → dominant headline → support/evidence → visual event → restrained Tiro signature
```

The order describes information hierarchy, not fixed screen coordinates. Generated imagery stays text-free. Headline, support, proof, and brand signature live in an editable design layer.

## 1. Feature release

**Viewer must understand:** what changed in Tiro.

Lead with the feature or product change. Use a recognizable product cue, structural metaphor, or real verified product fragment. Show benefit in support copy; do not make an abstract brand idea compete with the release.

```text
Label: Product update / New
Headline: <feature change>
Support: <what the user can now do>
Evidence: product cue, before/after relationship, or named capability
```

Suitable vocabulary: Shared Surface, Context Rooms, Compressed Time. Avoid generic launch confetti and vague “a new era” copy.

## 2. Security certification

**Viewer must understand:** what proof Tiro obtained.

Lead with the exact certification or verified trust event. Use proof hierarchy, documentary material, or a restrained evidence block. A visual seal may be abstract only; never fabricate official seal content.

```text
Label: Trust & Security
Headline: <exact certification or trust fact>
Support: <verified meaning or scope>
Evidence: certification name, type, issuer/source, verified date if supplied
```

Suitable vocabulary: paper relief, vellum, alignment, archive. Avoid blue cybersecurity, locks, shields, grids of code, and unverified “secure” claims.

## 3. Device or software support

**Viewer must understand:** what now works with Tiro.

Lead with the supported target. Repeat it in a compact compatibility block only when repetition removes ambiguity. Use connection, continuity, scale relationship, or a real supported interface.

```text
Label: New support
Headline: <Tiro now supports X>
Support: <what becomes possible>
Evidence: verified device/platform/integration list
```

Use moodboard reference 07 as the craft bar. Avoid floating glossy device mockups, copied vendor advertising, and unsupported platform chips.

## 4. Voice capability or strength

**Viewer must understand:** which voice-to-record benefit is real.

Lead with a verified user benefit or process. A process rail such as `녹음 → 전사 → 요약` can serve as evidence when those stages are real. Use metrics only with a current source and defined conditions.

```text
Label: Voice intelligence / Voice in Tiro
Headline: <verified benefit>
Support: <context or limitation>
Evidence: processing flow, sourced metric, language/support fact
```

Suitable vocabulary: After the Meeting, Compressed Time, layered threads settling into ordered record. Avoid neon waves, microphones, podcast imagery, and unsourced accuracy or speed claims.

## 5. Investment or company milestone

**Viewer must understand:** what verified company event occurred.

Lead with the event and its significance. Use turning point, layered progress, expanded capacity, or a poised architectural event. Do not substitute generic growth symbolism for missing facts.

```text
Label: Company news
Headline: <verified event>
Support: <why it matters>
Evidence: amount, participant, date, or milestone only when supplied and verified
```

Use moodboard reference 08 as the craft bar. For layout studies without a real event, label all sample copy as hypothetical. Avoid rockets, arrows, finance charts, coins, and confetti.

## 6. General external news

**Viewer must understand:** the event itself.

Use a flexible editorial module only after confirming the story does not belong to a more specific evidence pattern. The generic frame must still name what happened; “새로운 소식을 전합니다” alone is not sufficient final copy.

```text
Label: Tiro news / specific category
Headline: <event>
Support: <why the audience should care>
Evidence: event-specific fact or source
```

Suitable vocabulary: Living Archive, Modular Nota, paper windows, records connected by one line. Avoid bulletin-board clutter and category-neutral decoration.

## Channel adaptation

Start from one canonical composition. Current v1 reference canvas is 1200×675 for Tiro blog/social studies. Before final export:

1. verify the destination's current dimensions and safe areas;
2. preserve headline priority and evidence, not the exact crop;
3. define which visual material may crop and which copy may reflow;
4. recheck Korean line breaks and optical centering for each aspect ratio;
5. never stretch or merely center-crop a layout when the message field loses hierarchy.
