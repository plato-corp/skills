# Visual review

Compare the actual reference image(s) and the actual saved output side by side, at master size and at thumbnail. This is a structural and craft review by a human or agent looking at the real files; it is not a score.

## What the review compares

For each reference the plan marked `preserve` or `change`:

- **preserve** — the trait is still present and unaltered in the output. If it drifted, record a discrepancy.
- **change** — the trait changed in the intended direction. If it stayed the same or changed wrongly, record a discrepancy.
- **free** — no constraint; note only if it introduced a new problem.

Also examine, at both sizes:

- **hierarchy** — one focal event (or, for ambient/solid, one calm dominant field) reads first; the release zone stays usable for later copy and logo.
- **craft** — edges, material honesty, cropping, and brand-asset fidelity hold up at master size and do not collapse at thumbnail.

## Recorded criteria

Record every required criterion with one disposition and concrete evidence (what you saw in which file at which size):

- `pass` — verified present/correct with evidence.
- `fix` — a real discrepancy that must be corrected before release.
- `unverified` — could not be confirmed from the available files.

There is no numeric floor. `fix` and `unverified` block release; only a set with no `fix` and no `unverified` is finished. A raw graphic is never itself a finished channel deliverable.

## What review cannot establish

The review confirms structural correspondence between planned intent and the actual files. It cannot prove the generation tool was actually invoked as recorded, cannot prove authorship order, and does not certify artistic quality. File timestamps and SHA snapshots are convenience/integrity records, not cryptographic proof that planning preceded generation.
